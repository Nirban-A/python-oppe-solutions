???+ abstract "⚡ Quick Reference"
    **Type:** Full I/O problem

    **Core idea:** At row `i`, the main diagonal star is at column `i` and the secondary diagonal star is at column `n-1-i`. If they coincide, print one `*`; otherwise print both with spaces between.

    ```python
    n = int(input())
    for i in range(n):
        main = i
        sec  = n - 1 - i
        if main == sec:
            print(' ' * main + '*')
        else:
            left, right = min(main, sec), max(main, sec)
            print(' ' * left + '*' + ' ' * (right - left - 1) + '*')
    ```

    **Key rules:**
    - Main diagonal: column = `i` (row index)
    - Secondary diagonal: column = `n - 1 - i`
    - Diagonals meet when `i == n - 1 - i`, i.e. the middle row of an odd `n`
    - Interior spaces = `right - left - 1`
    - No trailing spaces -- rows always end with `*`

## Problem Statement

!!! note "Problem"
    Given `n >= 3`, print an `n × n` hollow X pattern. A `*` appears on the main diagonal (col = row) and the secondary diagonal (col = n-1-row). Where both diagonals meet, print a single `*`. No trailing spaces.

## Understanding the problem

For each row `i`, compute which columns get a `*`:

| Row `i` | Main col (`i`) | Sec col (`n-1-i`) | Same? | Line (n=5) |
|---------|---------------|-------------------|-------|-----------|
| 0 | 0 | 4 | no | `*   *` |
| 1 | 1 | 3 | no | ` * *` |
| 2 | 2 | 2 | ✅ | `  *` |
| 3 | 3 | 1 | no | ` * *` |
| 4 | 4 | 0 | no | `*   *` |

For rows where the two columns differ, `left = min(main, sec)` and `right = max(main, sec)`. The line is:
- `left` leading spaces
- `*`
- `right - left - 1` interior spaces
- `*`

!!! insight "min/max handle both halves of the X uniformly"
    In the top half, `main < sec` (left star from main diagonal, right from secondary). In the bottom half it flips. Using `min` and `max` to assign `left` and `right` covers both halves without a separate condition.

!!! insight "No trailing spaces because rows always end with *"
    Whether it's a single-star row or a two-star row, the last character printed is always `*`. No `.rstrip()` needed.

## Solution approaches

=== "Explanatory"

    ```python
    n = int(input())
    for i in range(n):
        main = i          # column of main diagonal star
        sec  = n - 1 - i  # column of secondary diagonal star

        if main == sec:
            # diagonals meet at the centre -- single star
            print(' ' * main + '*')
        else:
            # two stars; left is closer to column 0
            left  = min(main, sec)
            right = max(main, sec)
            interior = right - left - 1       # spaces between the two stars
            print(' ' * left + '*' + ' ' * interior + '*')
    ```

=== "Pythonic"

    ```python
    n = int(input())
    def row(i):
        m, s = i, n - 1 - i
        if m == s: return ' ' * m + '*'
        l, r = min(m, s), max(m, s)
        return ' ' * l + '*' + ' ' * (r - l - 1) + '*'
    print('\n'.join(row(i) for i in range(n)))
    ```

=== "Using lambda"

    ```python
    n = int(input())
    row = lambda i: (
        ' '*i+'*' if i == n-1-i
        else (lambda l,r: ' '*l+'*'+' '*(r-l-1)+'*')(min(i,n-1-i), max(i,n-1-i))
    )
    print('\n'.join(row(i) for i in range(n)))
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4>Diagonal columns from the row index</h4>
<p>In an n×n grid, the main diagonal is always at column = row (<code>i</code>), and the secondary diagonal is at column = <code>n-1-i</code>. These two formulas are the foundation of almost every X or diamond pattern problem.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4>Use <code>min/max</code> instead of top/bottom halves</h4>
<p>Rather than separate logic for rows above and below the centre, <code>left = min(main, sec)</code> and <code>right = max(main, sec)</code> always assign the correct positions regardless of which half the row is in.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4>Interior spaces = right - left - 1</h4>
<p>The number of spaces between two stars at column positions <code>left</code> and <code>right</code> is <code>right - left - 1</code>. This is a general formula: distance between positions minus the two stars themselves.</p>
</div>
