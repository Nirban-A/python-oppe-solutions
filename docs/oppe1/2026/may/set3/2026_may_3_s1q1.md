???+ abstract "⚡ Quick Reference"
    **Function:** `is_tens_digit_greater(num: int) -> bool`

    **Core idea:** Extract digits using `//` and `%`, then compare.

    ```python
    def is_tens_digit_greater(num):
        return (num // 10) > (num % 10)
    ```

    **Key rules:**
    - Tens digit = `num // 10`
    - Ones digit = `num % 10`
    - Return `True` only if tens digit is strictly greater

---

## Problem Statement

!!! note "Problem"
    Write a function `is_tens_digit_greater(num)` that takes a positive two-digit integer and returns `True` if the tens digit is strictly greater than the ones digit, `False` otherwise.

## Understanding the problem

For any two-digit number, integer division and modulo extract the two digits:

| `num` | `num // 10` (tens) | `num % 10` (ones) | tens > ones? |
|-------|--------------------|--------------------|--------------|
| 54 | 5 | 4 | ✅ `True` |
| 33 | 3 | 3 | ✗ `False` (equal, not greater) |
| 27 | 2 | 7 | ✗ `False` |
| 91 | 9 | 1 | ✅ `True` |

!!! insight "// and % are the standard digit extraction tools"
    For a two-digit number: `num // 10` drops the ones place (integer division by 10), and `num % 10` isolates the ones place (remainder when divided by 10). This generalises -- for any n-digit number, `% 10` always gives the last digit and `// 10` removes it.

---

## Solution approaches

=== "Explanatory"

    ```python
    def is_tens_digit_greater(num: int) -> bool:
        tens = num // 10    # integer division removes the ones digit
        ones = num % 10     # remainder gives the ones digit
        return tens > ones
    ```

=== "Pythonic"

    ```python
    def is_tens_digit_greater(num: int) -> bool:
        return (num // 10) > (num % 10)
    ```

=== "Using lambda"

    ```python
    is_tens_digit_greater = lambda num: (num // 10) > (num % 10)
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4>Digit extraction with <code>//</code> and <code>%</code></h4>
<p><code>num // 10</code> gives the tens digit; <code>num % 10</code> gives the ones digit. This is the standard arithmetic approach -- no string conversion needed. It generalises to any position: <code>// 100 % 10</code> gives the hundreds digit, and so on.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4>Comparison returns a bool directly</h4>
<p><code>tens > ones</code> already evaluates to <code>True</code> or <code>False</code> -- no need to wrap it in <code>if tens > ones: return True else: return False</code>. The comparison expression is the return value.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4>String alternative: <code>str(num)[0]</code></h4>
<p>An alternative is <code>int(str(num)[0]) > int(str(num)[1])</code> -- convert to string, index the characters, convert back to int. It works but is slower and less idiomatic than the arithmetic approach for simple digit extraction.</p>
</div>
