???+ abstract "⚡ Quick Reference"
    **Function:** `reverse_each_word(words: list) -> list`

    **Core idea:** Apply `[::-1]` to every string in the list via a list comprehension.

    ```python
    def reverse_each_word(words):
        return [w[::-1] for w in words]
    ```

    **Key rules:**
    - Reverse each string independently
    - Return a new list -- don't modify the original
    - Empty list input returns an empty list

---

## Problem Statement

!!! note "Problem"
    Write a function `reverse_each_word(words)` that takes a list of strings and returns a new list where every string is reversed. All elements are guaranteed to be strings.

## Understanding the problem

Each word is reversed independently -- the order of words in the list stays the same, only the characters within each word are reversed:

| Input word | Reversed |
|------------|----------|
| `"apple"` | `"elppa"` |
| `"cat"` | `"tac"` |
| `"python"` | `"nohtyp"` |

!!! insight "[::-1] works on any sequence"
    The slice `s[::-1]` reverses any sequence -- strings, lists, or tuples. For strings it returns a new string (strings are immutable in Python), so there's no in-place modification to worry about.

---

## Solution approaches

=== "Explanatory"

    ```python
    def reverse_each_word(words: list) -> list:
        result = []
        for w in words:
            result.append(w[::-1])   # reverse each word and collect
        return result
    ```

=== "Pythonic"

    ```python
    def reverse_each_word(words: list) -> list:
        return [w[::-1] for w in words]
    ```

=== "Using lambda"

    ```python
    reverse_each_word = lambda words: list(map(lambda w: w[::-1], words))
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4>Slice reversal: <code>s[::-1]</code></h4>
<p>A slice with step <code>-1</code> traverses the sequence backwards, producing a reversed copy. It works on strings, lists, and tuples. For strings it returns a new string since strings are immutable.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4>List comprehension for element-wise transforms</h4>
<p><code>[f(x) for x in iterable]</code> applies a function to every element and collects the results into a new list. This is the idiomatic replacement for a <code>for</code> loop with <code>.append()</code>.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4><code>map()</code> as a functional alternative</h4>
<p><code>map(lambda w: w[::-1], words)</code> applies the reversal lazily to each element. Wrapping in <code>list()</code> materialises it. Both <code>map</code> and list comprehensions produce the same result -- use whichever reads more clearly.</p>
</div>
