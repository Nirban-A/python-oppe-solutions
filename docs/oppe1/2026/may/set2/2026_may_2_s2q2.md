???+ abstract "⚡ Quick Reference"
    **Type:** Full I/O problem

    **Core idea:** Read the matrix, compute row sums, find the max, then use `list.index()` to get the first occurrence.

    ```python
    m, n = map(int, input().split())
    rows = [list(map(int, input().split())) for _ in range(m)]
    sums = [sum(row) for row in rows]
    max_sum = max(sums)
    print(sums.index(max_sum))
    print(max_sum)
    ```

    **Key rules:**
    - Output is two lines: index first, then sum
    - `list.index()` returns the first occurrence automatically
    - Row indices are 0-based

## Problem Statement

!!! note "Problem"
    Read an `m × n` integer matrix. Print the 0-based index of the row with the maximum sum, followed by that maximum sum. If multiple rows tie, print the index of the first one.

## Understanding the problem

For the first example:

| Row index | Values | Sum |
|-----------|--------|-----|
| 0 | `1 2 3 4` | 10 |
| 1 | `5 5 5 5` | 20 ← max |
| 2 | `2 2 2 2` | 8 |

Output: index `1`, sum `20`.

!!! insight "list.index() always returns the first match"
    `sums.index(max_sum)` scans left to right and stops at the first element equal to `max_sum`. This handles the tie-breaking rule for free -- no need to track the index manually or write extra logic.

!!! insight "Separate max() and index() instead of argmax"
    Python has no built-in `argmax`. The clean pattern is: compute `max_sum = max(sums)`, then find where it lives with `sums.index(max_sum)`. Avoid iterating manually with a running max and index variable -- the two-liner above is clearer and less error-prone.

## Solution approaches

=== "Explanatory"

    ```python
    m, n = map(int, input().split())

    # Read the matrix
    rows = []
    for _ in range(m):
        row = list(map(int, input().split()))
        rows.append(row)

    # Compute row sums
    sums = [sum(row) for row in rows]

    # Find max and its first index
    max_sum = max(sums)
    max_idx = sums.index(max_sum)   # first occurrence

    print(max_idx)
    print(max_sum)
    ```

=== "Pythonic"

    ```python
    m, n = map(int, input().split())
    sums = [sum(map(int, input().split())) for _ in range(m)]
    max_sum = max(sums)
    print(sums.index(max_sum))
    print(max_sum)
    ```

=== "Using lambda"

    ```python
    m, n = map(int, input().split())
    sums = list(map(lambda _: sum(map(int, input().split())), range(m)))
    max_sum = max(sums)
    print(sums.index(max_sum))
    print(max_sum)
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4><code>list.index()</code> for first-occurrence lookup</h4>
<p><code>sums.index(max_sum)</code> scans left to right and returns the index of the first element equal to <code>max_sum</code>. This gives the tie-breaking "first row wins" rule for free -- no extra conditional logic needed.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4>Reading a matrix with a list comprehension</h4>
<p><code>[list(map(int, input().split())) for _ in range(m)]</code> reads all rows in one expression. Each <code>input().split()</code> gives string tokens; <code>map(int, ...)</code> converts them to integers; <code>list()</code> materialises the result.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4>Skipping storage when only sums are needed</h4>
<p>The Pythonic version computes <code>sum(...)</code> on each row as it is read, storing only the sums list rather than the full matrix. For large inputs this halves memory usage -- the original rows are discarded immediately.</p>
</div>
