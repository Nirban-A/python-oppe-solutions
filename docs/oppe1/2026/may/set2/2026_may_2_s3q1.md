???+ abstract "⚡ Quick Reference"
    **Function:** `filter_houses(data: dict, category: str) -> set`

    **Core idea:** For each house, compute avg / max / min / spread, then test the condition for the requested category.

    ```python
    def filter_houses(data, category):
        result = set()
        for house, usage in data.items():
            avg = sum(usage) / len(usage)
            mn, mx = min(usage), max(usage)
            if   category == 'high_usage'                and avg >= 500:       result.add(house)
            elif category == 'moderate_usage'            and 200 <= avg < 500: result.add(house)
            elif category == 'low_consumption_all_months' and mx <= 200:       result.add(house)
            elif category == 'stable_usage'              and mx - mn <= 50:    result.add(house)
        return result
    ```

    **Key rules:**
    - `high_usage`: avg >= 500
    - `moderate_usage`: 200 <= avg < 500
    - `low_consumption_all_months`: every month <= 200, so `max <= 200`
    - `stable_usage`: max - min <= 50

## Problem Statement

!!! note "Problem"
    Given a dictionary `data` mapping house names to lists of monthly electricity consumption values (units), return a set of house names matching the given `category`:

    - `'high_usage'` -- average >= 500
    - `'moderate_usage'` -- average in [200, 500)
    - `'low_consumption_all_months'` -- every monthly value <= 200
    - `'stable_usage'` -- max - min <= 50

!!! note "Similar problem"
    This question follows the same four-category filter pattern as **S3Q1 of 2026 May Set 1** (Workout Data Analytics). The structure, thresholds, and logic differ, but the approach is identical.

```python
data = {

    "House_C": [700, 650, 720],
    "House_D": [250, 300, 275, 290],

}
```

## Understanding the problem

Each category maps to a single statistic:

| Statistic | Used by |
|-----------|---------|
| `avg = sum / len` | `high_usage`, `moderate_usage` |
| `max(usage)` | `low_consumption_all_months` |
| `max - min` | `stable_usage` |

**Full trace of all five houses:**

| House | Values | Avg | Max | Spread | HU | MU | LCA | SU |
|-------|--------|-----|-----|--------|----|----|-----|-----|
| House_A | [400,480,500] | 460 | 500 | 100 | | ✅ | | |
| House_B | [120,180,190] | 163 | 190 | 70 | | | ✅ | |
| House_C | [700,650,720] | 690 | 720 | 70 | ✅ | | | |
| House_D | [250,300,275,290] | 279 | 300 | 50 | | ✅ | | ✅ |
| House_E | [150,160,155] | 155 | 160 | 10 | | | ✅ | ✅ |

!!! insight "low_consumption_all_months uses max(), not avg()"
    The condition requires every month to be <= 200. Checking `max(usage) <= 200` is sufficient -- if the highest value passes, all values pass. House_A has avg 460 but also max 500 > 200, so it's excluded even though some months are low.

!!! insight "stable_usage: spread = 50 qualifies (<=, not <)"
    House_D has spread exactly 50, which satisfies `<= 50`. Watch the boundary -- the condition is inclusive on 50.

## Solution approaches

=== "Explanatory"

    ```python
    def filter_houses(data: dict, category: str) -> set:
        result = set()
        for house, usage in data.items():
            avg    = sum(usage) / len(usage)
            minimum = min(usage)
            maximum = max(usage)
            spread  = maximum - minimum

            if category == 'high_usage':
                if avg >= 500:
                    result.add(house)
            elif category == 'moderate_usage':
                if 200 <= avg < 500:
                    result.add(house)
            elif category == 'low_consumption_all_months':
                if maximum <= 200:         # max <= 200 means all values <= 200
                    result.add(house)
            elif category == 'stable_usage':
                if spread <= 50:
                    result.add(house)
        return result
    ```

=== "Pythonic"

    ```python
    def filter_houses(data: dict, category: str) -> set:
        conditions = {
            'high_usage':                  lambda u: sum(u)/len(u) >= 500,
            'moderate_usage':              lambda u: 200 <= sum(u)/len(u) < 500,
            'low_consumption_all_months':  lambda u: max(u) <= 200,
            'stable_usage':                lambda u: max(u) - min(u) <= 50,
        }
        test = conditions[category]
        return {house for house, usage in data.items() if test(usage)}
    ```

=== "Using lambda"

    ```python
    def filter_houses(data: dict, category: str) -> set:
        avg  = lambda u: sum(u) / len(u)
        test = {
            'high_usage':                  lambda u: avg(u) >= 500,
            'moderate_usage':              lambda u: 200 <= avg(u) < 500,
            'low_consumption_all_months':  lambda u: max(u) <= 200,
            'stable_usage':                lambda u: max(u) - min(u) <= 50,
        }[category]
        return {h for h, u in data.items() if test(u)}
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4>Use <code>max()</code> for "all elements" conditions</h4>
<p>Checking <code>max(usage) <= 200</code> is equivalent to <code>all(x <= 200 for x in usage)</code>. If the largest value satisfies the upper bound, every value does. It's more concise and avoids a full iteration.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4>Dict of lambdas for clean dispatch</h4>
<p>Storing each category's rule as a lambda in a dict replaces a long <code>if/elif</code> chain. Look up the right function with <code>conditions[category]</code> and apply it. Adding a new category is just one more dict entry.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4>Set comprehension for filtering</h4>
<p><code>{house for house, usage in data.items() if test(usage)}</code> expresses the filter in one line that reads almost like the problem statement: "give me all houses where the test holds."</p>
</div>
