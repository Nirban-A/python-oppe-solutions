???+ abstract "⚡ Quick Reference"
    **Function:** `double_if_even_else_square(n) -> int`

    **Core idea:** Check parity with `n % 2 == 0`, then return `2*n` or `n**2`.

    ```python
    def double_if_even_else_square(n):
        return 2 * n if n % 2 == 0 else n ** 2
    ```

    **Key rules:**
    - Even (`n % 2 == 0`): return `2 * n`
    - Odd: return `n ** 2`
    - Works for negative integers and zero (`0` is even)

---

## Problem Statement

!!! note "Problem"
    Write a function `double_if_even_else_square(n)` that doubles `n` if it is even, or returns `n` squared if it is odd.

## Understanding the problem

| `n` | Even? | Operation | Result |
|-----|-------|-----------|--------|
| `8` | ✅ | `2 × 8` | `16` |
| `9` | ✗ | `9²` | `81` |
| `0` | ✅ | `2 × 0` | `0` |
| `-4` | ✅ | `2 × -4` | `-8` |
| `-3` | ✗ | `(-3)²` | `9` |

!!! insight "n % 2 works correctly for negative numbers in Python"
    In Python, `%` always returns a non-negative result when the divisor is positive. So `-3 % 2 == 1` (odd) and `-4 % 2 == 0` (even) -- both behave as expected. This differs from some other languages where `%` can return negative values.

## Solution approaches

=== "Explanatory"

    ```python
    def double_if_even_else_square(n):
        if n % 2 == 0:   # even check
            return 2 * n
        else:
            return n ** 2
    ```

=== "Pythonic"

    ```python
    def double_if_even_else_square(n):
        return 2 * n if n % 2 == 0 else n ** 2
    ```

=== "Using lambda"

    ```python
    double_if_even_else_square = lambda n: 2 * n if n % 2 == 0 else n ** 2
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4>Parity check: <code>n % 2 == 0</code></h4>
<p>The modulo operator <code>%</code> gives the remainder after division. <code>n % 2 == 0</code> means no remainder when dividing by 2 -- the definition of even. Equivalently, <code>n % 2 != 0</code> (or <code>n % 2 == 1</code>) means odd.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4>Ternary expression: <code>a if condition else b</code></h4>
<p>Python's inline conditional <code>value_if_true if condition else value_if_false</code> collapses a two-branch <code>if/else</code> into one line. Best used when both branches are short expressions, as here.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4>Exponentiation: <code>n ** 2</code></h4>
<p><code>**</code> is Python's power operator. <code>n ** 2</code> is equivalent to <code>n * n</code> but reads more naturally as "n squared". Both work; <code>**</code> is preferred for clarity.</p>
</div>
