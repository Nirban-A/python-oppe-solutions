    **Type:** Full I/O problem

    **Core idea:** Three row types -- top border, middle (border only), bottom border. Middle rows end with `#` so no trailing spaces.

    ```python
    n = int(input())
    for i in range(n):
        if i == 0 or i == n - 1:
            print('#' * n)
        else:
            print('#' + ' ' * (n - 2) + '#')
    ```

    **Key rules:**
    - Row 0 and row n-1: `#` × n
    - Every middle row: `#` + (n-2) spaces + `#`
    - No trailing spaces -- middle rows end with `#`, not a space

## Problem Statement

!!! note "Problem"
    Given `n`, print an `n × n` hollow square using `#`. Only the border is filled; interior cells are spaces. No trailing spaces after the last `#` on any row. `n >= 2` always.

## Understanding the problem

Every row falls into one of three types:

| Row | Condition | Content |
|-----|-----------|---------|
| Top | `i == 0` | `#` × n |
| Middle | `0 < i < n-1` | `#` + (n-2) spaces + `#` |
| Bottom | `i == n-1` | `#` × n |

For `n = 4`, that gives:

```
####        ← top border
#  #        ← middle (n-2 = 2 spaces between the #s)
#  #        ← middle
####        ← bottom border
```

!!! insight "No trailing spaces because middle rows end with #"
    The hollow middle row is `'#' + ' ' * (n-2) + '#'`. The rightmost character is always `#`, so there is nothing to strip. A naive approach of building an n-wide string with spaces and replacing corners can leave trailing spaces -- building the string directly avoids this.

!!! insight "n = 2 edge case"
    When `n = 2` there are no middle rows (rows 1 to n-2 is an empty range). Both rows 0 and 1 are border rows, so the output is just two `##` lines. The loop handles this automatically without any special case.

## Solution approaches

=== "Explanatory"

    ```python
    n = int(input())
    for i in range(n):
        if i == 0 or i == n - 1:
            # Top and bottom border: all hashes
            print('#' * n)
        else:
            # Middle rows: hash, interior spaces, hash
            interior = ' ' * (n - 2)
            print('#' + interior + '#')
    ```

=== "Pythonic"

    ```python
    n = int(input())
    border = '#' * n
    middle = '#' + ' ' * (n - 2) + '#'
    rows   = [border] + [middle] * (n - 2) + [border]
    print('\n'.join(rows))
    ```

=== "Using lambda"

    ```python
    n = int(input())
    row = lambda i: '#'*n if i in (0, n-1) else '#'+' '*(n-2)+'#'
    print('\n'.join(row(i) for i in range(n)))
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4>Three-type row classification</h4>
<p>Pattern printing usually reduces to classifying each row. Here the three types are: top border, middle (hollow), bottom border. The condition <code>i == 0 or i == n-1</code> handles both borders in one branch.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4>Build strings directly to avoid trailing spaces</h4>
<p>Constructing the middle row as <code>'#' + ' '*(n-2) + '#'</code> guarantees no trailing spaces. Avoid building an all-space string and then replacing positions -- that leaves spaces at the end if you forget to strip.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4>Precompute repeated strings</h4>
<p>The Pythonic approach builds <code>border</code> and <code>middle</code> once, then assembles the full list with <code>[border] + [middle]*(n-2) + [border]</code>. Cleaner than computing the same string in every loop iteration.</p>
</div>
