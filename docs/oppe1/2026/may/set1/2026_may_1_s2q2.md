???+ abstract "⚡ Quick Reference"
    **Type:** Full I/O problem

    **Core idea:** Read `n` lines, count every character that satisfies `ch.isdigit()`.

    ```python
    n = int(input())
    count = 0
    for _ in range(n):
        count += sum(1 for ch in input() if ch.isdigit())
    print(count)
    ```

    **Key rules:**
    - Count digits `0`-`9` only, across all lines combined
    - `str.isdigit()` is the cleanest check
    - Print a single integer at the end

## Problem Statement

!!! note "Problem"
    Read `n` (the number of lines), then `n` lines of text. Print the total count of numeric digit characters (`0`-`9`) present across all lines.

## Understanding the problem

Walk through the first example character by character:

| Line | Content | Digits found |
|------|---------|-------------|
| 1 | `hello 123` | `1`, `2`, `3` |
| 2 | `world 45` | `4`, `5` |
| 3 | `no digits here` | (none) |

Total: `3 + 2 + 0 = 5`

!!! insight "isdigit() vs checking '0' <= ch <= '9'"
    Both work for plain ASCII digits, but `str.isdigit()` is more readable and idiomatic. Note that `str.isdigit()` also returns `True` for some Unicode digit characters (like superscripts), but for OPPE inputs with standard ASCII text this makes no practical difference.

---

## Solution approaches

=== "Explanatory"

    ```python
    n = int(input())
    count = 0
    for _ in range(n):
        line = input()
        for ch in line:
            if ch.isdigit():   # True for '0' through '9'
                count += 1
    print(count)
    ```

=== "Pythonic"

    ```python
    n = int(input())
    text = [input() for _ in range(n)]
    print(sum(ch.isdigit() for line in text for ch in line))
    ```

=== "Using lambda"

    ```python
    n = int(input())
    lines = [input() for _ in range(n)]
    digit_count = lambda lines: sum(1 for line in lines for ch in line if ch.isdigit())
    print(digit_count(lines))
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4><code>str.isdigit()</code> for character classification</h4>
<p>Python's string methods let you classify characters without manual range checks. <code>ch.isdigit()</code> is cleaner than <code>'0' &lt;= ch &lt;= '9'</code> and signals intent clearly.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4>Flattening nested iteration with a generator</h4>
<p><code>sum(ch.isdigit() for line in text for ch in line)</code> uses a nested generator expression to iterate all characters across all lines in one pass. <code>bool</code> values are treated as <code>0</code>/<code>1</code> by <code>sum()</code>, so no explicit <code>if</code> is needed.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4>Running total vs. collect-then-count</h4>
<p>For large inputs, updating a running <code>count</code> inside the loop uses O(1) memory. The list comprehension approach stores all lines first -- both are fine for OPPE inputs, but the running total is worth knowing for general use.</p>
</div>
