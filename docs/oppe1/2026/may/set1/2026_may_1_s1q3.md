???+ abstract "⚡ Quick Reference"
    **Function:** `make_dict_from_elems_in_index(keys, values, index) -> dict`

    **Core idea:** Index both lists at the same position, wrap in a dict literal.

    ```python
    def make_dict_from_elems_in_index(keys, values, index):
        return {keys[index]: values[index]}
    ```

    **Key rules:**
    - Returns a dict with exactly one key-value pair
    - Index is applied independently to both lists (they can have different lengths)
    - Negative indices work as normal Python indexing

---

## Problem Statement

!!! note "Problem"
    Write a function `make_dict_from_elems_in_index(keys, values, index)` that returns a dictionary with a single key-value pair, where the key is `keys[index]` and the value is `values[index]`. The index is always valid for both lists.

## Understanding the problem

The two lists are indexed independently at the same position:

| Index | `keys` | `values` | Result |
|-------|--------|----------|--------|
| `0` | `'apple'` | `10` | `{'apple': 10}` |
| `1` | `'banana'` | `20` | `{'banana': 20}` |
| `2` | `'cherry'` | `30` | `{'cherry': 30}` |
| `-1` | `'cherry'` | `40` | `{'cherry': 40}` |

!!! insight "Lists can have different lengths"
    Notice that `keys` has 3 elements and `values` has 4. The index is applied to each list separately, so `values[-1]` gives `40` (last of 4) while `keys[-1]` gives `'cherry'` (last of 3). This is by design -- the problem guarantees the index is valid for both.

---

## Solution approaches

=== "Explanatory"

    ```python
    def make_dict_from_elems_in_index(keys, values, index: int) -> dict:
        key   = keys[index]    # pick the key from the keys list
        value = values[index]  # pick the value from the values list
        return {key: value}    # wrap in a single-pair dict
    ```

=== "Pythonic"

    ```python
    def make_dict_from_elems_in_index(keys, values, index: int) -> dict:
        return {keys[index]: values[index]}
    ```

=== "Using lambda"

    ```python
    make_dict_from_elems_in_index = lambda keys, values, index: {keys[index]: values[index]}
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4>Single-pair dict literal: <code>{k: v}</code></h4>
<p>The simplest way to create a one-item dictionary is the literal <code>{key: value}</code>. No need for <code>dict()</code> or <code>.update()</code> when you already have the key and value in hand.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4>Negative indexing</h4>
<p>Python supports negative indices: <code>-1</code> is the last element, <code>-2</code> is second-to-last, and so on. They work identically on any list regardless of its length.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4>Independent indexing on two lists</h4>
<p>The two lists don't need to be the same length -- the same index just resolves independently for each. <code>keys[index]</code> and <code>values[index]</code> are two separate lookups that happen to use the same integer.</p>
</div>
