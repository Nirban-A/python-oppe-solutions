    **Function:** `join_even_index_strings(words: list) -> str`

    **Core idea:** Concatenate the elements at index 0 and index 2.

    ```python
    def join_even_index_strings(words):

    ```

    - Even indices are 0 and 2 only
    - Join means concatenation, no separator

## Problem Statement

!!! note "Problem"
    Write a function `join_even_index_strings(words)` that takes a list of exactly four strings and returns a new string formed by joining the strings at even indices (index `0` and index `2`).

## Understanding the problem

A four-element list has indices `0, 1, 2, 3`. The even ones are `0` and `2`.

| Index | `["apple", "banana", "cherry", "mango"]` | Even? |
|-------|------------------------------------------|-------|
| 0 | `"apple"` | ✅ |
| 1 | `"banana"` | ✗ |
| 2 | `"cherry"` | ✅ |
| 3 | `"mango"` | ✗ |

Result: `"apple" + "cherry"` = `"applecherry"`

!!! insight "Three ways to pick even indices"
    Since the list is always length 4, you can use direct indexing (`words[0] + words[2]`), slicing with step (`words[::2]`), or a general `i % 2 == 0` check. All three give the same result here -- direct indexing is the simplest.

---

## Solution approaches

=== "Explanatory"

    ```python
    def join_even_index_strings(words: list) -> str:
        # Even indices of a 4-element list are always 0 and 2
        first  = words[0]   # index 0 -- even
        second = words[2]   # index 2 -- even
        return first + second
    ```

=== "Pythonic"

    ```python
    def join_even_index_strings(words: list) -> str:
        # Slice with step 2 picks every other element starting at index 0
        return ''.join(words[::2])
    ```

=== "Using lambda"

    ```python
    join_even_index_strings = lambda words: ''.join(words[i] for i in range(0, len(words), 2))
    ```

## Key takeaways

<div class="pb-cards">

<div class="pb-card">
<div class="pb-card-num">01</div>
<h4>Slice with step: <code>list[::2]</code></h4>
<p><code>words[::2]</code> returns every element at an even index -- <code>words[0]</code>, <code>words[2]</code>, <code>words[4]</code>, … It works for any list length, not just four.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">02</div>
<h4><code>''.join(iterable)</code> for concatenation</h4>
<p><code>''.join([...])</code> concatenates all strings in an iterable with no separator. Cleaner than chaining <code>+</code> operators, especially when the number of elements can vary.</p>
</div>

<div class="pb-card">
<div class="pb-card-num">03</div>
<h4>Fixed length vs. general solution</h4>
<p>When the list is guaranteed to be length 4, <code>words[0] + words[2]</code> is perfectly valid and clear. For variable-length lists, prefer <code>words[::2]</code> or <code>i % 2 == 0</code> so the logic scales.</p>
</div>
